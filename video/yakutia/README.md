# Видео «Демография Республики Саха (Якутия)»

`yakutia-demography.mp4` — 1920×1080, 30 fps, 77 секунд, H.264 (формат для YouTube).

## Как устроено
- `index.html` — вся анимация. Каждый кадр рисуется на `<canvas>` как функция времени.
  Если открыть файл в браузере, ролик проигрывается вживую (удобно смотреть правки).
- `render.cjs` — Playwright покадрово снимает холст, ffmpeg склеивает кадры в MP4.

## Как править
В начале `index.html`:
- `DATA` — все цифры и список источников;
- `C` — цвета (фон-амбре: `bgA`…`bgD`), `FONT` / `HEAD` — шрифты;
- `SCENES` — порядок и длительность сцен (секунды), `DURATION` — общая длина.

## Как пересобрать
```bash
node render.cjs                  # полный рендер, ~5 минут
node render.cjs --stills 4,12    # PNG-кадры на 4-й и 12-й секунде для проверки
```
