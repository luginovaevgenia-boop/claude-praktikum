# Тест Средиземья

Интерактивный тест по «Властелину колец»: 12 вопросов, звание по итогам и общая таблица результатов.

## 1. Опубликовать сайт (GitHub Pages)

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В блоке **Build and deployment** выберите *Source: Deploy from a branch*, ветку **main** и папку **/ (root)** → **Save**.
3. Через 1–2 минуты тест будет по адресу:
   `https://luginovaevgenia-boop.github.io/claude-praktikum/lotr/`

Сайт строится из ветки `main`, поэтому изменения из рабочей ветки сначала нужно влить в `main` (через pull request).

## 2. Собирать результаты (Google Таблица)

GitHub Pages умеет только показывать страницы, но не хранить данные. Поэтому результаты пишутся в вашу Google Таблицу — бесплатно, и видны только вам (в таблице) и игрокам (в таблице лидеров на сайте: имя, баллы, звание).

1. Создайте новую Google Таблицу (sheets.new).
2. **Расширения → Apps Script**. Удалите всё в редакторе и вставьте код из файла [`apps-script.gs`](apps-script.gs). Сохраните.
3. **Начать развертывание → Новое развертывание** → тип **Веб-приложение**.
   - *Запуск от имени*: **От моего имени**
   - *У кого есть доступ*: **Все**
4. **Развернуть**, разрешите доступ к таблице (Google покажет предупреждение «приложение не проверено» — это ваш собственный скрипт: *Дополнительно → Перейти к проекту*).
5. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. В файле [`index.html`](index.html) найдите строку
   ```js
   const RESULTS_URL = '';
   ```
   и вставьте адрес между кавычками. Сохраните и отправьте изменения в `main`.

Готово: каждое прохождение появится новой строкой на листе «Результаты», а на сайте — в «Летописи героев».

Пока адрес не вставлен, тест работает, но результаты видны только на том устройстве, где тест проходили.
