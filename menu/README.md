# Меню на неделю

Веб-приложение: одной кнопкой составляет меню на неделю (завтрак, обед, ужин) и считает список покупок.

## Запуск

Откройте `menu/index.html` через любой статический сервер, например:

    cd menu && python3 -m http.server 8080

и перейдите на http://localhost:8080. Без настройки Firebase данные хранятся только в этом браузере.

## Общее меню для всей семьи (Firebase)

1. Откройте https://console.firebase.google.com, нажмите «Создать проект» (аналитику можно отключить).
2. В проекте: «Сборка» → «Firestore Database» → «Создать базу данных» (режим производства, любой регион).
3. Во вкладке «Правила» вставьте содержимое файла `firestore.rules` и нажмите «Опубликовать».
4. «Настройки проекта» → «Ваши приложения» → значок `</>` (веб) → зарегистрируйте приложение и скопируйте объект `firebaseConfig`.
5. В файле `firebase-config.js` замените `null` на этот объект: `export const FIREBASE_CONFIG = { ... };`.
6. Откройте приложение, нажмите «Создать» семью и запишите код. На телефонах остальных членов семьи введите тот же код.

Код семьи — это и есть «пароль» к меню: не показывайте его посторонним.

## Как поделиться с семьёй

1. Выложите папку `menu/` на любой хостинг статических сайтов (например, GitHub Pages) и отправьте ссылку.
2. Каждый открывает ссылку и вводит код семьи (он на вкладке «Ещё»).
3. На телефоне: меню браузера → «Добавить на главный экран», и приложение будет открываться как обычное.
